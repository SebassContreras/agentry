# Roadmap

Specs in execution order. Status is `todo`, `in progress` or `done`: set it to `in progress` when work starts and to `done` when the spec closes, not per task (the spec's checkboxes track the tasks). Only the next spec is written in full; write more only to run them in parallel (`parallel.md`). A new ID is the highest in the table plus one; `done` rows stay as the ID register until nothing depends on them.
